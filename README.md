# Hemera — descargas

Aquí se publican las versiones de la app de escritorio de **Hemera** (chat de voz, texto,
grupos, torneos y partidas privadas de Warzone). El código vive en otro repositorio privado:
aquí solo están los instaladores.

## Descargar

**[⬇️ Descargar Hemera para Windows](https://github.com/alejosgre19/hemera-releases/releases/latest/download/Hemera-Setup.exe)**

1. Abre `Hemera-Setup.exe`. Se instala en unos segundos, sin permisos de administrador.
2. Si Windows avisa con "Windows protegió su PC", pulsa **Más información → Ejecutar de todas formas**.
3. Hemera queda en el menú Inicio, en la búsqueda de Windows y en el escritorio.

A partir de ahí **se actualiza sola**: cada vez que la abres busca versiones nuevas, las
descarga y se reinicia ya actualizada (como Discord).

¿Prefieres no instalar nada? En cada versión está también `Hemera.exe` (portable), pero ese
no se actualiza solo. Y desde el navegador: https://hemera-1.onrender.com
